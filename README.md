## About This Repository

This repository documents my proving grounds practice solutions. I’ve completed all penetration testing tracks offered by OffSec. However, out of respect for OffSec’s content policies, I’ve chosen to publish notes only for the **Essential and Foundations tracks**.
You won’t find walkthroughs for the other two tracks, **Penetration Testing Advanced** and **Red Teaming**, anywhere online.
